## 结论

本机官方 ZCode Server 3.16.3 可在不启动 Electron、不设置 DISPLAY/WAYLAND_DISPLAY、不使用 Xvfb 的情况下，为不同账号执行真实代码任务。已跑通单实例原会话续接，以及 daemon 调度两个账号、两个 worktree 并行修改和核验的流程。

这些是本机、小规模测试结论，不保证其他版本、活动资格或所有桌面工具具有相同表现。

## 已实现

- TypeScript 单包，CLI、常驻 daemon、stdio MCP 使用统一方法 schema。
- 账号导入去重、加密存储、官方格式凭据注入、独立目录和进程身份检查。
- 官方二进制 Channel RPC、项目登记、会话创建、模型选择、事件订阅、审批回复、取消及快照查询。
- SQLite 持久化派发意图、会话标识、幂等键、Worker/Workspace 占用、事件和 revision。
- 异步派发、有界等待、真实测试命令执行、不可变结果与累计工作区差异快照。
- 未知执行状态保留占用，不自动重发；显式对账仅根据匹配原回合的终止证据释放占用。

## 真实运行发现

1. **设备状态初始化**：全新无头目录缺少 `v2/telemetry-state.json` 中的设备标识，官方额度接口返回 HTTP 400。复用当前真实机器已存在的 deviceMid 后额度请求成功。只写入隔离目录，不修改默认客户端，不制造或轮换设备身份。
2. **项目登记**：创建会话前需通过官方 project 服务注册工作区；仅提供 cwd 不够。
3. **事件协议**：server protocol 为 1，会话 wire version 为 3。实际逻辑帧的 epoch 来自订阅确认及 snapshot，不能依赖不存在的外层字段。
4. **模型推理档位**：`account:zai-start-plan/GLM-5.3-Flash` 要求 reasoningLevel。适配器保留已选会话的实际档位，本次为 max。
5. **任务接收与完成不同**：模型准备失败、审批等待、回合完成都按官方事件区分；不把 ACK 当作成功。

## 单实例验证

Worker A 使用一个原生会话：

- 修复隔离 arithmetic fixture，Node 测试通过。
- 同会话追加第三参数需求，两个 Node 测试通过，额外断言 `add(2,3,4) === 9` 通过。
- 实际处理 Edit/Bash 的 allowOnce 审批。
- 连接关闭后重新连接，恢复原来待审批的回合，没有重新派发提示词。
- 官方 Start Plan 余额从首个模型任务前的 500,000,000 变为两回合结束后的 499,758,119。

早期初始化或参数错误的尝试保留为诊断记录；它们在模型执行前失败，不计为成功任务。

## 双账号 daemon 验证

通过本项目 daemon 派发任务，两个 Worker 的 running 状态存在重叠。两个工作树从同一测试基线创建，各自修复 `sum.cjs` 中的减法错误，变为加法；daemon 分别执行 `node --test sum.test.cjs`，退出码均为 0。

| 实例 | 执行结果 | 任务前官方余额 | 任务后官方余额 | 观测差值 |
| --- | --- | ---: | ---: | ---: |
| A | succeeded，文件检查与测试通过 | 499,758,119 | 499,678,488 | 79,631 |
| B | succeeded，文件检查与测试通过 | 500,000,000 | 499,894,024 | 105,976 |

两边均明确选择 `account:zai-start-plan`，没有切换到付费 provider。余额差值是官方余额观测，不等同于本地输出 token 数，也不能用于推导未来任务成本。

## 测试与证据

常规验证命令：

```bash
npm run typecheck
npm test
```

最终结果：TypeScript 检查通过，42 个自动测试全部通过。

测试覆盖协议编码与真实脱敏样本、审批和终止事件、凭据兼容性、独立进程身份、SQLite SIGKILL 恢复、跨进程占用竞争、幂等请求、等待竞态、MCP stdio 往返、工作树累计快照及生命周期互斥。

主动发起真实模型任务的脚本不会被 `npm test` 自动执行：

- `scripts/live-runtime.ts`：底层单实例协议验证，需要显式参数。
- `scripts/live-coordinator.ts`：需要显式指定测试 pool 且已有 a/b 实例，执行双账号真实任务。

本地详细证据保存在 Git 忽略的 `runtime/p1/`：

- `workers/a/artifacts/live-smoke-evidence.json` 及对应协议、事件记录。
- `validation/coordinator-report.json`：双账号任务、外部测试及额度前后数据。
- `scheduler/state.db` 和任务产物目录：持久化状态、结果与补丁。

本次测试实例 A/B 和测试 daemon 已停止，工作区、会话及证据保留。默认 ZCode 服务与 Cockpit 仓库未修改。
