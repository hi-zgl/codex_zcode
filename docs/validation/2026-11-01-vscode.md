## 边界和未执行项

### Remote SSH 与真实模型补充验收

用户随后指定使用既有 Worker `a`、新隔离 workspace，修复加法函数并运行 `node --test`。启动前已用 SQLite backup 保存 schema 1 数据库，确认原有两个任务均已成功，再启动新 daemon 完成迁移。仅启动 Worker `a`，官方 runtime 为 `3.16.3`。

- 新 workspace：`f7044fa3-155d-40f6-b2b3-22ae090adbd3`；独立 fixture 的 base commit 为 `57fc92cf2425613ff7ffe06c54520d963416f303`，基线测试退出码为 1。
- 真实任务：`task_0a54a5d3-af4f-4c03-8cc0-be0f1192aae0`，使用 `GLM-5.3-Flash`、`build`、新会话、最多 3 次同会话繁忙续跑。用户在 UI 答复 Edit 后，实际文件变为加法，随后出现运行 `node --test` 的 Bash 审批；后续任务成功结束。
- 用户上传的 Remote SSH 截图确认执行侧 `asus (ssh-remote)` 已连接正确的 `runtime/p1`，任务/资源树和工作台显示该真实任务等待审批。此截图证明远程连接与展示；后续审批操作由用户反馈和任务执行状态补充验证，原生 Diff 与文件选择器仍未获得用户验收证据。
- 首次界面连接的是默认 `~/.zcode_pool`，产生 `DAEMON_UNAVAILABLE`；用户修改 Remote Settings 的 pool 路径后连接成功。
- 真实 Edit 审批暴露 Host 兼容问题：原生 `freeText: true` 被误判为不支持的决策类型，全文读取因此失败。官方 3.16.3 类型注释与协议测试确认该字段仅允许拒绝时附带反馈，是可选能力，不影响 `allowOnce`/`deny` 的既有选项；不能将这次失败记为审批验收通过。
- 已修复上述兼容问题，并复用脱敏的官方 permission fixture 覆盖缺省/false/true 与恶意响应参数。扩展 build、57 项单元测试、7 项集成测试通过。使用修复后的实际 Host ActionService 对当前审批进行受 RPC 白名单限制的只读验证，返回 `loadedComplete: true`，完整 1,973 字节及 SHA-256 校验通过，识别 accept/decline；未发送审批答复。这不代替用户重载后在真实 UI 中批准的验收。
- opt-in runner 的 300 秒观察窗口已结束，未取消任务、答复审批或重发请求。后续沿用相同 taskId 观察，未重新派发。输入、回执与备份保存在忽略的 `runtime/p1/validation/ui-real/`。

- 最终 daemon 状态为 `succeeded`、revision 146、`executionStopped: true`、`leaseHeld: false`，无待审批或 blocker。daemon 独立核验 `node --test` 退出码 0，3 项测试全部通过；仅修改 `sum.cjs`，测试文件未修改。
- 交付 manifest 可用且列表完整，包含 1 个变更文件。经 UI API 读取不可变 base/final 字节并逐侧核对 SHA-256，确认 `a - b` → `a + b`。这验证了交付读取链路，不替代 Remote SSH 原生 Diff 窗口的人工验收。

### 尚未完成及能力边界

- 新 UI 真实模型任务、人工审批后的继续执行、独立核验与不可变交付读取均已验证。既有真实 Start Plan/双账号记录见[原实测报告](2026-11-01.md)，不能替代新 UI 链路证据。`test:real-model` 默认零连接跳过，审批由人在 UI 操作。
- Remote SSH 已验证连接、任务展示与人工审批后执行；原生 Diff/文件选择器尚未完成人工验收，WSL 实机未验收。Codespaces/容器也未列为已验环境。纯 Windows/macOS 本地 daemon 与纯浏览器 VS Code 不支持。
- 已检查语义标签、Tab/选项卡键盘行为、焦点恢复及浏览器布局；未运行完整人工屏幕阅读器流程。
- 原生 runtime 没有已验证的 CAS 答复接口；本地串行/hash 校验不消除上游快照至发送的竞态。只有经核实的普通 permission UUID、支持的 Bash/Edit/Write/Read schema 可操作，其他类型或不完整来源只读；pending 消失只记 `resolved_unattributed`。
- 快照持有调度 lease，但不是原子文件系统快照；旧任务不补造历史，失败/取消可能没有快照。gitlink、非 UTF-8 路径、二进制或大文件按明确元数据/读取限制展示。
- 全池变更 feed、进一步资源分页、自动调度/换账号、账号续期、合并/清理、daemon 自动安装/启动管理仍属于设计中明确后续或排除的范围，不随本次 UI 增加。
