# 账号隔离与官方运行时

[设计入口](README.md) · [任务调度](task-orchestration.md) · [验证范围](../validation/current.md)

每个账号对应独立官方 Server 与数据目录。账号凭据由本地账号库加密保存，运行时所需凭据由启动器注入；MCP、Webview、普通日志和文档不返回凭据。原始导出文件只用于导入与恢复。

## 受支持路径

当前适配官方 ZCode Server 3.16.3、server protocol 1，只使用账号对应的 Start Plan，不静默回退到 Coding Plan 或其他付费 provider。supervisor 管理 `zcode serve`，不启动 Electron，不依赖 Xvfb，也不修改官方安装包。进程就绪不等于认证、额度或模型执行成功。

凭据目录 `ZCODE_DATA_BASE_DIR` 与 `--server-root` 配对；`ZCODE_STORAGE_DIR`、`ZCODE_SESSION_DB_PATH` 指向该实例自己的原生存储。启动器复用本机已经初始化的设备标识，不创建或轮换身份，不改默认客户端状态。没有本机初始化状态时，需先完成官方初始化。

Worker 生命周期按 PID、启动时间、进程组与实例路径核对，不以旧 PID 或固定端口判断身份。发现原进程与当前协议后才能接管；无法证实归属或活动状态时不强停、不复用。停止必须先没有活动或未知任务占用。

## 禁止内部派生

新的受控执行会话使用官方 `createSession` 的工具禁止配置与 `persistence: deferred`，确保首次输入前按受支持路径持久化会话，再通过 V4 订阅与发送路径执行。禁止 Agent、Task、SendMessage、workflow、offpeak、cron 等派生入口；提示词提醒只是辅助。

已经存在的不受控旧会话无法热加该限制：允许只读保留，拒绝继续发送新的任务。需要受控新执行时，使用新策略会话；不为了升级策略终止既有活动任务。禁止内部派生不限制外部指挥组织其他独立验收资源。

## 新鲜只读观察

原任务的核查新建只读 WebSocket 连接，订阅原 session ID 并等待初始新快照；不创建、恢复、重派或发送提示词。已有订阅的本地 `syncHistory` 投影不自动视作新鲜核查。

观察必须匹配原 command、turn、session 和工作目录。瞬时 `activeWorks` 为空不证明可以释放：队列、待处理或后台工作仍可能启动；原生终止状态和无活动执行需要同时成立。历史尾部窗口缺少原回合时保持未知。

实际模型失败只采集 `readSessionDebug.networkEntries`，使用稳定 `eventKey` 持久去重，以 `queryId` 核对原 command；不把 `apiRetry` 或按请求重置的 attempt 当作次数。该源只提供最近 100 条，前后锚点不重叠、查询失败、既有历史未核实或归属不明时，观测完整性保持未知。失败累计只表示已采集的实际事件；计数源故障不阻断已经独立证实的执行终态，也不触发重做。

## 额度语义

直接查询 Start Plan 的 billing/balance，按对应官方字段归一化。不同套餐或单位的窗口不相加；Coding Plan 接口失败不是 Start Plan 为零的证据。查询失败保留旧值并明确失败与时间。

导入额度只表示旧快照，MCP 标明导入来源与陈旧状态，不编造观察时间、单位或比例。已确认耗尽的账号不能因低额度阈值设为 0 而重新成为可派发资源。

窗口 `percentageUsed` 表示已用比例，缺失为 `null`；摘要 `percentage` 表示剩余比例，归一为 0–100。不能按数值小于 1 来猜已用或剩余语义。存在多个窗口时突出当前最约束的已知窗口，展开查看具体用量与官方时间。

一次性额度的 `expires_at` 是到期时间，不表示重置或恢复；只有有明确周期依据的时间才展示为重置。未知数据、未知套餐、未知比例和未知时间均保持未知。

凭据库、会话数据库、工作区与备份边界见[存储布局](../storage-layout.md)。
