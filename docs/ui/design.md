## 页面与交互

“任务监控”提供共享池与当前项目视角。Host 根据活动文件、工作区和已有总任务/工作目录生成只读项目选项；尚未准备 worktree 的待办也能按项目查看。能唯一确定项目时默认该项目；已有手动选择不被后续刷新覆盖，多根不明时保持共享池。任务与账号摘要并列，常用全池上限、暂停新派发与资源入口在概况可达。

共享列表有界，明确显示载入数量和截断；选择项目会实际按 `repository_path` 查询，定位已知总任务按 `work_id` 查询，不对全池最近窗口做本地过滤后冒充项目范围。当前范围的刷新保留查询条件，迟到的旧范围结果被丢弃；全池决策发现使用独立只读待办投影，不覆盖当前展示。项目选项与查询范围都是 Host 展示元数据，不是另一份任务业务状态，也不触发目录准备。

总任务同页显示目标、当前指挥与配额、实施和验收、整个阶段图及账号分配。图按实际 `dependsOn` 布局，支持串行、并行、汇合及变化的阶段数量。窄屏仍保留分支/汇合关系与前置文字，不把视觉排列伪装成串行依赖。展开阶段查看子任务、每项账号、执行事实与进入交付的入口。

未开始、进行中、受阻/待处理、返工、已确认完成均有状态文字与视觉标记。只有指挥确认才点亮；返工移除完成状态。实施执行结束与验收分别显示，独立外部验收可在账号已释放后继续。阶段操作不作为日常用户审批流程，UI 不代指挥确认语义完成。

集中待办保存资源不足、全部低额度和需要判断的事项，并关联总任务。资源不足显示实际可用数，用户明确确认后才部分推进；其他事项可进入额度资源处理后重新检查，语义决定仍回到指挥入口。VS Code 对需要用户决定的待办去重通知；普通可恢复错误不逐次弹窗。面板隐藏时保留低频只读待办发现，显式断开后停止查询。

“额度与资源”是独立页面。默认显示账号标识、健康/启用状态、最约束的已知余量、当前指挥任务、分类累计错误与更新时间；展开查看官方窗口、用量、时间与来源。手动刷新和可见时每 60 秒自动查询并存；失败、过旧、未知值明确展示，不虚构余额或恢复时间。

错误记录按账号、任务与时间查询，每次已观测的实际错误计数，恢复后保留累计和“已恢复”标记。查询、账号摘要和任务执行同时显示观测完整性；未知范围的 0 次不代表没有发生。账号详情可直接进入对应错误范围。日志和交付默认摘要，审批正文、详细事件、不可变差异和产物按需读取。

设置默认：重试 5 秒、恢复等待让号 2 分钟、静默核查 15 分钟、低额度 5%、新指挥配额 2。界面以秒/分钟显示，接口以毫秒保存；次数仅用于统计。各指挥配额、全池上限和本次临时配额不互相静默覆盖。

## Host 与 Webview

| 位置 | 责任 |
| --- | --- |
| `src/host/actions.ts`、`client.ts` | 能力协商、Unix socket、可信投影、并发读取、明确写动作与异步失效检查 |
| `src/host/protocol.ts`、`router.ts` | 固定消息白名单、输入大小、generation 与重复 ID 控制 |
| `src/webview/` | 原生 DOM、展示、筛选与表单草稿；不访问 Node、socket、凭据或任意路径 |
| `src/shared/ui-contract.ts` | 后台 UI 参数、响应 schema、能力与大小限制 |
| `src/shared/work-contract.ts` | 总任务、阶段、验收、错误的唯一领域合同 |
| `src/daemon/ui.ts` | 展示投影、真实错误聚合、额度、完整审批和不可变工件读取 |

引用上述源码路径均相对仓库或扩展根目录。Host bundle 禁止包含 daemon/core/runtime 实现，Webview bundle 禁止包含 Host 或运行依赖。CSP 禁止网络连接；消息只传固定动作及已知标识，不传通用 RPC 或可执行文件路径。

## 读取与写入

| 接口 | 用途 |
| --- | --- |
| `ui_capabilities` | 协商 API major、实例/store 身份、能力与预算 |
| `ui_get_work_overview` | 读取有界总任务、阶段依赖、验收、待办、指挥与真实账号错误累计 |
| `ui_get_error_stats` | account/task/work 和起止时间筛选；已采集累计、观测完整性，事件尾部最多 100 条 |
| `ui_list_tasks` / `ui_get_task_detail` | 执行分页与详情、停止依据、累计尝试与最近 25 条尝试 |
| `ui_get_quota` / `ui_probe_quota` | 已保存快照 / 明确官方查询；两者不发起模型任务 |
| `ui_list/get/read/respond_approval` | 完整审批、分片、指纹与答复回执 |
| `ui_get_artifact_manifest` / `ui_list_artifact_files` / `ui_read_artifact_file` | 固定 task/manifest/file/side 的历史工件读取 |

写动作复用后台当前方法：池策略、指挥配额、账号启用、明确用户待办决定，以及已有的账号导入、Worker、目录、派发、取消与恢复。字段以源码 schema 为准，不在文档复制大段 JSON。改变全池上限须有用户明确指令；点击面板控件是该范围的明确动作。

API v1 每个响应最多 256 KiB，分片最多 64 KiB；总任务列表超预算会减少旧任务数量并返回 `total/truncated`，不改写 ID。单个过大对象拒绝返回，不能把截断内容当成完整事实。任务分页 cursor 绑定筛选、排序、store/实例与 revision；失效时重新读取列表。旧后台的最近 50 条窗口明确标注，不能称为全历史。

## 审批、交付与不确定结果

受限工作区只读；Host 在写入前及异步文件选择、存储返回后再次检查 trust、generation、能力和当前目标。写结果超时或断连视为未知，保留原请求身份并检查，禁止自动重发。

审批必须有完整支持的普通 permission 来源、当前 task/attempt/command/session/turn 归属、revision 和正文 SHA-256。批准前完整读取并验证；未知操作、缺参数、敏感内容无法完整呈现等情况只读。持久答复意图与回执防重复；原生 ACK 不证明回答已采用，审批消失可记为来源不明的解决。上游没有已验证的原子 CAS，不能宣称本地校验消除了所有上游竞态。

交付使用完成时保存的 base/final 字节，Diff 相对 workspace 基线累计，包含前序改动的可能性必须明确。路径、符号链接、二进制和文件大小按合同限制；旧任务缺快照明确不可用，不读取当前磁盘伪装历史。“本客户端已审阅”只绑定 manifest 的本地标记，不代表验收、整合或总任务完成。独立验收使用程序提供的临时固定副本；总任务结束后目录会清理，界面保留固定交付与工件引用，不能把临时路径当作永久可打开的成果。

键盘、焦点、展开状态、窄宽屏、深浅/高对比及文字对比由现有浏览器检查覆盖；人工屏幕阅读器与 Remote/WSL 边界见[当前验证](../validation/current.md)。
