# ZCode Pool

ZCode 共享账号池的 VS Code 工作台。外部指挥负责安排与验收，官方 ZCode Server 执行；后台独立运行，关闭面板不停止任务。

安装 VSIX 到 Linux 执行侧，准备 Node.js 24+ 与官方 ZCode Server 3.16.3。打开 **ZCode Pool: Open Workbench**，确认连接目录，点击“启动后台并连接”，导入账号。VSIX 已包含本项目后台、CLI 和 MCP。

点击“连接 Codex / 生成 MCP 配置”，按说明一次添加到同一执行侧的 Codex，再重新连接。生成配置不会自动修改 Codex 设置，也不代表已经连接。日常直接在指挥入口说明项目目标与验收要求。

工作台提供共享池/项目视角、总任务和实际阶段依赖、实施与验收、集中待办、独立额度页、分类错误与配额设置。阶段由指挥确认完成，返工会撤销点亮。默认 5 秒重试、2 分钟安全恢复等待让号、15 分钟静默只读核查，均可设置；次数只统计，不限制总重试。

“断开面板”不停止任务；“收工”在没有活动或未知占用时停止实例与后台。升级扩展不会自动重启旧后台。受限工作区只读。

源码仓库中的完整说明位于 `docs/ui/implementation.md`（使用与开发）、`docs/ui/design.md`（界面与接口）和 `docs/validation/current.md`（实际验证边界）。已安装工作台可直接生成连接说明并打开连接帮助。
